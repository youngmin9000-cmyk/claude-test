1 답 ②

함수 ⟦f(x)⟧는 ⟦x=1⟧에서 ⟦lim _{x -> 1} {f(x)}⟧의 값이 존재하지 않으므로 불연속이고, ⟦x=2⟧에서 ⟦lim _{x -> 2} {f(x) != f(2)}⟧이므로 불연속이다. 

그러므로 불연속인 ⟦x⟧의 값은 ⟦2⟧개이다.  

즉, ⟦m=2⟧

또, ⟦f(x)⟧는 ⟦x=1,````x=2⟧에서 불연속이므로 미분가능하지 않고, ⟦x=3⟧에서

⟦lim _{x -> 3+} {{f(x)-f(x)} over {x-3}  != } lim _{x -> 3-} {{f(x)-f(x)} over {x-3}}⟧이므로

미분가능하지 않다.

그러므로 미분가능하지 않은 ⟦x⟧의 값은 ⟦3⟧개이다.

즉,⟦`n=3⟧

따라서 ⟦m+n=2+3=5⟧

2 답 ③

ㄱ. ⟦f(x) = LEFT |  x RIGHT |⟧는 ⟦x=0⟧에서 연속이지만
⟦lim _{x -> 0+} {{f(x)-f(0)} over {x-0}} = lim _{x -> 0+} {{LEFT | x RIGHT |} over {x}} = lim _{x -> 0+} {{x} over {x}} =1⟧
⟦lim _{x -> 0-} {{f(x)-f(0)} over {x-0}} = lim _{x -> 0-} {{LEFT | x RIGHT |} over {x}} = lim _{x -> 0-} {{-x} over {x}} =-1⟧
따라서 ⟦f(x)⟧는 ⟦x=0⟧에서 미분가능하지 않다.

ㄴ. ⟦g(x) = x LEFT |  x RIGHT | = cases { x^2 &(x ge 0) # -x^2 ```&(x <0) }⟧은 ⟦x=0⟧에서 연속이고
⟦lim _{x -> 0+} {{g(x)-g(0)} over {x-0}} = lim _{x -> 0+} {{x  ^{2}} over {x}} =0⟧
⟦lim _{x -> 0-} {{g(x)-g(0)} over {x-0}} = lim _{x -> 0-} {{-x  ^{2}} over {x}} =0⟧
이므로 ⟦g prime (0)=0⟧이다. 따라서 ⟦g(x)⟧는 ⟦x=0⟧에서 미분가능하다.

ㄷ. ⟦h(x) = x  [x] = cases { -x ``& ( -1<x<0) # 0 & (0 le x <1) }⟧은 ⟦x=0⟧에서 
연속이지만
⟦lim _{x -> 0+} {{h(x)-h(0)} over {x-0}} = lim _{x -> 0+} {{0} over {x}} =0⟧
⟦lim _{x -> 0-} {{h(x)-h(0)} over {x-0}} = lim _{x -> 0-} {{-x} over {x}} =-1⟧
따라서 ⟦h(x)⟧는 ⟦x=0⟧에서 미분가능하지 않다.

그러므로 ⟦x=0⟧에서 연속이지만 ⟦x=0⟧에서 미분가능하지 않은 함수는 ㄱ, ㄷ이다.

3 답 ③

ㄱ. ⟦lim _{x -> 0+} {(-x  ^{2} )} = lim _{x -> 0-} {(x  ^{2} )} =0⟧이고, ⟦f(0)=0⟧이므로 ⟦f(x)⟧는 ⟦x=0⟧에서 연속이다. (참)

ㄴ. ⟦lim _{x -> 0+} {{f(x)-f(0)} over {x-0}} = lim _{x -> 0+} {{x  ^{2} -0} over {x}} = lim _{x -> 0+} {x} =0⟧

⟦lim _{x -> 0-} {{f(x)-f(0)} over {x-0}} = lim _{x -> 0-} {{-x  ^{2} -0} over {x}} ⟧
