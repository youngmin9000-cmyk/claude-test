⟦f LEFT ( x RIGHT ) =x  ^{3} -x  ^{2} +ax+2⟧라고 하면

⟦f`' LEFT ( x RIGHT ) =3x  ^{2} -2x+a⟧

곡선 ⟦y=f LEFT ( x RIGHT )⟧는 점 ⟦LEFT ( 1,````3 RIGHT )⟧을 지나므로

⟦1-1+a+2=3⟧,  ⟦a=1⟧

점 ⟦LEFT ( 1,````3 RIGHT )⟧에서의 접선의 기울기는

⟦f`' LEFT ( 1 RIGHT ) =3-2+1=2⟧	

따라서 기울기가 ⟦2⟧이고 점 ⟦LEFT ( 1,````3 RIGHT )⟧을 지나는 접선의 방정식은

⟦y-3=2 LEFT ( x-1 RIGHT )⟧, 즉 ⟦y=2x+1⟧

따라서 ⟦b=2,````c=1⟧이므로

⟦abc=1  times  2 times  1=2⟧

2 답 ⟦{3}⟧

⟦f LEFT ( x RIGHT ) =x  ^{3} -2x  ^{2} +3⟧이라고 하면

⟦f`' LEFT ( x RIGHT ) =3x  ^{2} -4x⟧

⟦x=1⟧인 점에서의 접선의 기울기는

⟦f`' LEFT ( 1 RIGHT ) =3-4=-1⟧

⟦f LEFT ( 1 RIGHT ) =2⟧이므로 점 ⟦LEFT ( 1,````2 RIGHT )⟧에서의 접선의 방정식은

⟦y-2=- LEFT ( x-1 RIGHT )⟧, 즉 ⟦y=-x+3⟧

따라서 접선의 ⟦y⟧절편은 ⟦3⟧이다.

3 답  ③

⟦f LEFT ( x RIGHT ) =x LEFT ( x+1 RIGHT ) LEFT ( 2-x RIGHT )⟧라 하면

⟦f`' LEFT ( x RIGHT )⟧⟦= LEFT ( x+1 RIGHT ) LEFT ( 2-x RIGHT ) +x LEFT ( 2-x RIGHT ) -x LEFT ( x+1 RIGHT )⟧
⟦= LEFT ( 2-x RIGHT ) LEFT ( 2x+1 RIGHT ) -x  ^{2} -x⟧
⟦=-3x  ^{2} +2x+2⟧

⟦x=2⟧에서의 접선의 기울기는

⟦f`' LEFT ( 2 RIGHT ) =-12+4+2=-6⟧

따라서 접선에 수직인 직선의 기울기는 ⟦{1} over {6}⟧이므로 구하는 직선의 방정식은

⟦m+n= {1} over {6} + LEFT ( - {1} over {3} RIGHT ) =- {1} over {6}⟧
