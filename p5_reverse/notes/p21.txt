    02. 부정적분의 계산
    (소단원 평가(기초) 정답 및 풀이)
1 답 (1) ⟦2x^2 -x+C⟧	 
      (2) ⟦-x^3 +x^2 +C⟧
(단, ⟦C⟧는 부정적분)
(1) ⟦int⟧⟦(4x-1) dx⟧⟦= 4int  { x` } dx - int  { } dx⟧
⟦= 4   left (1 over 2 x^2   +C _1 right) - (x+C_2 )⟧
⟦= 2x^2 -x+4C_1 -C_2⟧
여기서 ⟦4C_1 -C_2 =C⟧로 나타내면
⟦int _{ } ^{ } { } (4x-1) dx⟧⟦=2x^2 -x+C⟧ 
(단, ⟦C⟧는 부정적분)
(2) ⟦int _{ } ^{ } { } (-3x^2 +2x) dx⟧⟦= -3int  { x^2 } dx +2 int  { x} dx⟧
⟦=  -3 left (1 over 3 x^3 +C_1  right ) +2 left (1 over 2 x^2 +C_2   right )⟧⟦= -x^3 +x^2  -3C_1 +2 C_2⟧
여기서 ⟦-3C_1 +2C_2 =C⟧로 나타내면
⟦int _{ } ^{ } { } (-3x^2 +2x) dx⟧⟦=-x^3 +x^2 +C⟧
(단, ⟦C⟧는 부정적분)
2 답 ⟦x^3 -2x^2 +2x+C⟧ (단, ⟦C⟧는 부정적분)
⟦int (3x^2 -4x+2)dx⟧
⟦ = 3int x^2 dx - 4 int { }x dx +2 int  { }dx⟧
⟦= 3 times 1 over 3 x^3 - 4 times 1 over 2 x^2 +2x +C⟧ 
⟦=x^3 -2x^2 +2x+C⟧  
(단, ⟦C⟧는 부정적분)
3 답 (1) ⟦2x^2 -5x+C⟧	 (2) ⟦- 1over3 x^3 +4x^2 +C⟧
    (3) ⟦x^4 -x^3 +x^2 +C⟧	 (4) ⟦1over3 x^3 +3x^2 -7x+C⟧
(단, ⟦C⟧는 부정적분)
(1) ⟦int (4x-5)dx⟧⟦= 4int  { x } dx -5 int  { } dx⟧
⟦= 4 times 1 over 2 x^2  - 5x+C⟧
⟦= 2x^2  -5x +C⟧
(단, ⟦C⟧는 부정적분)
(2) ⟦int (-x^2 +8x)dx⟧⟦= -int  { x^2 } dx +8 int  { x} dx⟧
⟦=  (- 1 ) times 1 over 3 x^3  + 8 times 1 over2 x^2 +C⟧
⟦ =- 1over3 x^3 +4x^2 +C⟧
(단, ⟦C⟧는 부정적분)
(3) ⟦int (4x^3 -3x^2 +2x)dx⟧
⟦ = 4int x^3 dx - 3 int { }x^2 dx +2 int  {x }dx⟧
⟦= 4 times 1 over 4 x^4  - 3 times 1 over 3 x^3 +2 times 1 over 2 x^2 +C⟧	
⟦ =x^4 -x^3 +x^2 +C⟧  (단, ⟦C⟧는 부정적분)
(4) ⟦int (x-1)(x+7) dx⟧
⟦= int (x^2 +6x-7) dx⟧
⟦ = int x^2 dx +6 int { }x dx -7 int  { }dx⟧
⟦= 1 over 3 x^3 +  6 times 1 over 2 x^2  -7 x +C⟧
⟦ = 1over3 x^3 +3x^2 -7x+C⟧ (단, ⟦C⟧는 부정적분)
4 답 ⟦f(x)=x^3 +x^2 -x+2⟧
⟦f'(x)=3x^2 +2x-1⟧이므로
⟦f(x) = int  { }(3x^2 +2x-1) dx ⟧
⟦= x^3 +x^2 -x+C⟧ (단, ⟦C⟧는 부정적분)
이때 ⟦f(0)=2⟧이므로 
⟦C=2⟧
따라서 ⟦f(x)=x^3 +x^2 -x+2⟧
5 답 (1) ⟦f(x)=3x^2 +x-1⟧ 
      (2) ⟦f(x)=-x^3 +4x^2 -5x+2⟧
(1) ⟦f'(x)=6x+1⟧이므로
⟦f(x) = int  { }(6x+1) dx ⟧
⟦=3x^2 +x+C⟧ (단, ⟦C⟧는 부정적분)
이때 ⟦f(0)=-1⟧이므로 
⟦C=-1⟧
따라서 ⟦f(x)=3x^2 +x-1⟧
(2) ⟦f'(x)=-3x^2 +8x-5⟧이므로
⟦f(x) = int  { }(-3x^2 + 8x-5) dx ⟧ 
⟦= -x^3 +4x^2 -5x+C⟧ (단, ⟦C⟧는 부정적분)
이때 ⟦f(1)=0⟧이므로 
⟦-1+4-5+C=0⟧
즉, ⟦C= 2⟧
따라서 ⟦f(x)=-x^3 +4x^2 -5x+2⟧
6 답 ⟦1 over 4 x^4  -2x^3 +x^2 -5x+C⟧ (단, ⟦C⟧는 부정적분)
⟦int{(x^3 -6x^2 +2x-5 )}dx⟧
⟦ = int x^3 dx - 6 int { }x^2  dx +2 int  { }xdx - 5 int  { }dx⟧
⟦= 1 over 4 x^4 - 6 times 1 over 3 x^3 +2 times 1 over 2 x^2 -5x +C⟧
⟦ = 1 over 4 x^4  -2x^3 +x^2 -5x+C⟧ (단, ⟦C⟧는 부정적분)
7 답 ⟦4 over 3 x^3 +6x^2 +9x+C⟧ (단, ⟦C⟧는 부정적분)
⟦int{(2x+3 )^2}dx = int { } (4x^2 +12x+9) dx⟧
⟦ = 4int x^2 dx  +12 int { }x dx +9 int  { }dx⟧
⟦= 4 times 1 over 3 x^3 +12 times 1 over 2 x^2 +9x +C⟧ ⟦= 4 over 3 x^3 +6x^2 +9x+C⟧  
(단, ⟦C⟧는 부정적분)
8 답 (1) ⟦x^3 -x^2 +4x+C⟧ 
       (2)  ⟦2 over 3 x^3 - 5 over 2 x^2 -3x+C⟧ 
(단, ⟦C⟧는 부정적분)
(1) ⟦int{(3x^2 -2x+4)}dx⟧
⟦ = 3int x^2 dx  -2 int { }x dx +4 int  { }dx⟧⟦=3 TIMES  {1} over {3} x  ^{3} +(-2) TIMES  {1} over {2} x  ^{2} +4x+C⟧ ⟦ =x^3 -x^2 +4x+C⟧  (단, ⟦C⟧는 부정적분)
(2) ⟦int{(2x+1)(x-3)}dx⟧
⟦ = int{(2x^2 -5x-3)}dx⟧
⟦ = 2int x^2 dx  -5 int { }x dx -3int  { }dx⟧⟦= 2 times 1 over 3 x^3 -5 times 1 over 2 x^2 -3x +C⟧ ⟦ = 2 over 3 x^3 - 5 over 2 x^2 -3x+C⟧ (단, ⟦C⟧는 부정적분)
9 답 ⟦f(x)= {1} over {4} x  ^{4} -x  ^{3} -3⟧
⟦f`'(x)=x^3 -3x^2 ⟧이므로
⟦f(x) = int  { } (x^3 -3x^2 ) dx ⟧
⟦= 1 over 4 x^4 -x^3 +C⟧ (단, ⟦C⟧는 부정적분)
이때 ⟦f(0)=-3⟧이므로 
⟦C=-3⟧
따라서 ⟦f(x)= {1} over {4} x  ^{4} -x  ^{3} -3⟧
10 답 ⟦f(x)=x^2 +2x-1⟧
곡선 ⟦y=f(x)⟧ 위의 점 ⟦(x⟧, ⟦y)⟧에서의 접선의 기울기는 ⟦2x+2⟧이므로
⟦f'(x)=2x+2⟧
⟦f(x) = int  { }(2x+2) dx ⟧
⟦= x^2 +2x+C⟧ (단, ⟦C⟧는 부정적분)
이때 이 곡선이 점 ⟦(1,~2)⟧를 지나므로 ⟦f(1)=2⟧, 즉 ⟦f(1) =1+2+C=2⟧, ⟦C= -1⟧
따라서 ⟦f(x)=x^2 +2x-1⟧
