# 서울공고 공통수학2 Ⅰ. 도형의 방정식 — 예상시험 7회분

| 파일 | 내용 |
|---|---|
| `1_학생용_실전예상시험_1-5회.pdf` | 정규 실전 예상시험 1~5회 (회차당 20문항: 객관식 16 + 서답형 4) |
| `2_학생용_최종점검_6-7회.pdf` | 시험 직전 최종 점검 6회(전체 범위), 7회(마지막 실전) |
| `3_정답및상세해설_1-7회.pdf` | 빠른 정답표 + 전 문항 단계별 해설 |
| `4_교사용_문항관리표.pdf` | 회차/번호/원교과서 위치/원유형/N·M/난이도/정답 |

- 문항 원본: 업로드 자료(미래엔 22개정 교과서 문제 모음) 1단원 전체(§1 평면좌표와 직선, §2 원의 방정식, §3 도형의 이동)
- `src/e1.py`~`e7.py`: 문항·선지·해설 데이터와 sympy 독립 검산식, `src/build.py`: 검산 후 XeLaTeX 조판
- 재생성: `cd src && python3 build.py` (모든 문항 검산을 통과해야만 PDF를 만듦)
